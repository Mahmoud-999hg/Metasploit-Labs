# Metasploit Pivoting Lab

## Project Overview
This project demonstrates a practical implementation of network penetration testing, focusing on brute-forcing and network pivoting within an isolated virtual lab environment (Metasploitable 3).

## Steps Implemented:
1. **FTP Brute-Forcing:** Conducted a dictionary attack using custom wordlists (`username` and `password`) via Metasploit.
2. **Pivoting & SOCKS Proxy:** Established a local SOCKS Proxy server running on port `1080` using `Socks 4a` protocol to route the internal network traffic.
3. **Documentation:** Included full screenshots, presentation slides, and the final lab report.
